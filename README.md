# NoCapAI - DeepFake Detection

🚨 Detect manipulated (deepfake) images and videos using AI.

## 🔍 Features
- Upload image or video
- Detect manipulation (fake/real) with warning alerts
- Beautiful Bootstrap UI
- Custom branding and logo
- Built with Flask (Python backend)

## 📦 Tech Stack
- Python 3.10+
- Flask
- Bootstrap 5
- HTML/CSS
- Git & GitHub
